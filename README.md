# geo-game (working title: Meridian)

A geography, history and general-knowledge game platform built for **unlimited replayability**. It includes map quizzes, shape deduction, pin-the-fact, an interactive atlas, rare-answer challenges, routing, ranking and history games, all in one product.

This repository currently contains the **implementation blueprint** (product, design, data and technical specifications). Application code will follow in phases.
